Manuel d’utilisation du simulateur

Les différents modes de jeu:

Découvrez le pilotage lors d’une initiation mémorable !

Apprenez à prendre en main le jeu lors d’un tutoriel accessible et intuitif.
Cliquez sur initiation en vol dans le bandeau situé au-dessus du jeu pour y accéder.

Découvrez les missions !

Que ce soit en solo ou en multi-joueurs ESME flight simulator offre une gamme assez large de missions pour tous les niveaux.
Les missions sont accessibles depuis le bandeau situé au-dessus du jeu, en cliquant sur les menus missions solo ou missions en multi-joueur.

Explorez le monde à votre façon !

Accéder depuis le bandeau situer au-dessus du jeu a un monde sans limite.
Le mode vol libre vous permet de vous déplacer librement dans le monde et de faire ce que vous voulez.

Météo:

Jour, nuit, jour, nuit:

Volez de jour ou de nuit comme bon vous semble en cliquant sur jour ou nuit dans le menu à droite de l'écran.

Des nuages à gogo:

Envie de plus de défis! Volez dans le brouillard ou dans une tempête en cliquant sur brouillard ou tempête dans le menu à droite de l'écran.

La couverture nuageuse change avec la météo. Traverser un nuage réduit fortement la visibilité : fiez-vous à vos instruments !

Eléments de jeu:

Les instruments de vol se situe sous l’écran. Vous pouvez y retrouver les instruments suivants :

  • Anémomètre (vitesse)
  • Altimètre
  • Variomètre
  • Horizon artificielle
  • Cap
  • Manette des gaz

Contrôles:

Les contrôles sont accessibles depuis l’onglet paramètres situé en haut à droite de l’écran.
Les contrôles sont :

ZPiquer (descendre)
SCabrer (monter)
QIncliner à gauche
DIncliner à droite
A / EPalonnier gauche / droite
EspaceAugmenter les gaz
Control / ShiftRéduire les gaz
RRevenir au point de départ (ou bouton ↺ Réinitialiser)
VVue cabine / vue extérieure (ou bouton 🎥)
FPlein écran (ou bouton ⛶)

Multijoueur:

Cliquez sur Multijoueur dans le bandeau au-dessus du jeu, puis choisissez votre pseudo.
Un joueur clique sur Créer une partie privée : un code à 6 caractères et un lien s’affichent. Les autres joueurs saisissent ce code puis cliquent sur Rejoindre, ou ouvrent simplement le lien.
Chaque joueur apparaît dans un Cessna de sa couleur, avec son pseudo au-dessus. La partie continue tant qu’il reste au moins un joueur.

Décrochage:

Si l’avion vole trop lentement (moins de 43 km/h environ), l’aile ne porte plus : c’est le décrochage.
L’alarme sonore Airbus (« STALL » suivi du « cricket ») retentit juste avant, puis le message DÉCROCHAGE clignote à l’écran. L’avion s’enfonce, le nez et une aile tombent et les commandes deviennent molles.
Pour en sortir : rendez la main (Z) pour reprendre de la vitesse et remettez les gaz (Espace).

Profil:

Gérer votre profil dans le menu profil situé en haut à droite de l’écran.
